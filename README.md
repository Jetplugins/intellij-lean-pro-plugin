# Lean Pro issue tracker

Report bugs and suggest improvements for **Lean Pro**, the JetBrains IDE plugin for Lean 4. Lean Pro is developed by JetPlugins independently of Lean FRO.

- [Report a bug](https://github.com/Jetplugins/intellij-lean-pro-plugin/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/Jetplugins/intellij-lean-pro-plugin/issues/new?template=feature_request.yml)
- [Browse existing issues](https://github.com/Jetplugins/intellij-lean-pro-plugin/issues)

For a bug report, include your Lean Pro version, IDE build number, operating system, and the Lean toolchain or `lean-toolchain` pin. A small `.lean` file or Lake project helps us reproduce the issue. Include the LSP4IJ version and, where relevant, the Mathlib revision, `lean-fmt` version, or `lldb-dap` version. Redact credentials, license keys, and private source code before sharing files, screenshots, or logs.

Use [private vulnerability reporting](https://github.com/Jetplugins/intellij-lean-pro-plugin/security/advisories/new) for security issues. See the [security policy](SECURITY.md).
