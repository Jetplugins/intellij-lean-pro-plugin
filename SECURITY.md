# Security policy

[Report a security vulnerability privately](https://github.com/Jetplugins/intellij-lean-pro-plugin/security/advisories/new) so the maintainers can investigate it with you.

Include the affected Lean Pro version, IDE name and build, operating system, Lean toolchain, the impact, and steps to reproduce. Redact credentials, license keys, and unrelated private information in reports and attachments.
